Hãy đọc AGENTS.md, README.md, docs/CHAT_HANDOFF.md và docs/TECHNICAL_SPEC.md trước khi làm gì khác. Đây là dự án game tương tác Toán lớp 2 bằng webcam laptop, một học sinh mỗi lượt, với hình và âm thanh đã đóng gói. Hãy kiểm tra code đã tạo, chạy npm install và npm run build, sửa lỗi kỹ thuật nếu có, rồi hướng dẫn tôi thử webcam nhận diện A/B/C/D và tư thế nghỉ. Ưu tiên độ ổn định và bảo vệ hình ảnh học sinh, không tự ý bổ sung backend/đăng nhập. Khi xong hãy báo các file đã thay đổi và cách chạy trên Windows.
